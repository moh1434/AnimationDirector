# Directing a storyboard

Read [Portrait direction](../../../REFERENCE_VIDEO_STUDY.md) for the shot decisions, examples and review questions shared by all directors. Use the project's measured `build/brief.md` and the user's original words for this video.

- For single narration, use the suggested cut points in the brief and word cues within each scene. For dialogue, follow [Story mode](../../../STORY_MODE.md) for clip-relative timing, speaker intervals, real-world scale and prop layers. Treat stage directions in a supplied script as creative material.
- Use [Storyboard fields](../../../STORYBOARD_GUIDE.md) for layout, pose, expression, timed props and camera syntax. For a close shot use the [portrait camera limits](../../../ART_STYLE.md#camera). A gesture, facial change or camera move should direct attention to a specific event.
- Look up valid names in `pnpm video catalog`. For a missing drawing use the project assets skill. For factual material use supplied or sourced images and verified labels.
- Validate, inspect the Shorts stills and review the sequence in the order given in [AGENTS.md](../../../AGENTS.md).
