# The World's Unluckiest Thief

A complete directed story. **The recordings in `voices/` are test placeholders** made with Windows' built-in
speech voice, so they sound robotic and have long pauses. They are not meant to be published.

To finish it, replace each file in `voices/` with the real recording of the same line (see `dialogue.json`),
then run:

```bash
pnpm video plan unluckiest-thief
```

```bash
pnpm video make unluckiest-thief
```

The storyboard is timed from the recordings, so it does not need retiming.
