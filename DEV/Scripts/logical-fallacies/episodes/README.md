# Episodes

Finished scripts, one file per episode: `NN-short-title.txt` (for example `01-every-famous-chef.txt`).

- `# STATUS: draft` on the first line: written by the AI, waiting for the user's review. Edit the file freely.
- `# STATUS: approved`: reviewed by the user and ready for the voices. Only these go to TTS, exactly as saved.

See "Voice-ready file" in `../RULES.md`.
